# SWYNEX Biological Dataset Selection

## 1. Project Title
Exploration of the Human OCA2 Pigmentation Gene Using NCBI

## 2. Objective
To select and describe a publicly available biological dataset and understand its biological significance using the NCBI database.

## 3. Dataset Information
- Gene symbol: OCA2
- Gene name: OCA2 melanosomal transmembrane protein
- Organism: Homo sapiens (human)
- NCBI Gene ID: 4948
- Chromosome: 15
- Database: NCBI Gene and NCBI Nucleotide
- Sequence type: mRNA
- RefSeq accession: NM_000275.3
- Sequence length: 3,143 nucleotides
- Format: FASTA

## 4. Dataset Source
NCBI Gene: https://www.ncbi.nlm.nih.gov/gene/4948

NCBI RefSeq: https://www.ncbi.nlm.nih.gov/nuccore/NM_000275.3

## 5. Biological Significance
The OCA2 gene encodes a protein involved in melanosome function and pigmentation. It contributes to melanin production and normal pigmentation of the eyes, skin, and hair. Certain variants in OCA2 are associated with oculocutaneous albinism type 2.

## 6. Research Question
What biological information can be obtained from the human OCA2 gene sequence, and how can this dataset support further bioinformatics analysis?

## 7. Potential Applications
- Nucleotide sequence analysis
- Gene annotation
- Comparative sequence analysis
- Exploration of genetic variation
- Study of pigmentation-related biology

## 8. Methodology
1. Searched for OCA2 in the NCBI Gene database.
2. Identified the human OCA2 gene using Gene ID 4948.
3. Opened the RefSeq mRNA record NM_000275.3.
4. Examined the sequence record and viewed the nucleotide sequence in FASTA format.
5. Recorded the dataset source, accession number, sequence length, and biological significance.

## 9. Conclusion
This activity provided practical experience in selecting a public biological dataset, retrieving a reference sequence, and documenting its biological relevance using NCBI resources.
